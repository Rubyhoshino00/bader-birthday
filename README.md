# Moonlit Chapter 25 — For Bader ✦

A responsive, anime-inspired birthday visual novel made by Mira for Bader's 25th birthday on **18 November**. The story is a warm friendship gift with a moonlit, mysterious atmosphere.

## Files
- `index.html` — all page sections and dialogue UI
- `style.css` — responsive design, night-sky visuals, animations
- `script.js` — interactive chapters, choices, replay, optional ambient tone
- `cover-art.png` — optional concept artwork included with the project

## Preview locally
Open `index.html` in a modern browser. The visual novel does not need a build step or server. An internet connection is used only for the optional Google Fonts import.

## Publish with GitHub Pages
1. Sign in to [GitHub](https://github.com/) and create a new **public** repository named `bader-birthday`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and optionally `cover-art.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to finish publishing. The site URL will appear on the Pages settings screen, usually `https://YOUR-USERNAME.github.io/bader-birthday/`.
7. Test the URL on your phone before sending it to Bader.

## Suggested birthday reveal
Send the link on 18 November with a short message such as:
> I made something small for you. Open it when you have a quiet moment ♡ Happy birthday, Bader.

## Personalization
The friendship message is deliberately warm without assuming a romantic relationship. Edit the final letter in `index.html` and the dialogue/choices in `script.js` to add a private joke or a shared memory.
